# Графіки відключень для Світлячка

[Графік Чернівецької області](data/chernivtsi.json) містить оприлюднені Чернівціобленерго графіки на сьогодні й завтра. Групи мають номери від 1 до 12. [Джерело](https://oblenergo.cv.ua/shutdowns/)

Для кожної дати за київським часом і групи записано 48 півгодин від опівночі. Значення `1` означає, що світло є, `0` — відключення, `3` — можливе заживлення. Поле `updated` містить час, коли збирач виявив зміну.

Перший запуск із сервера GitHub 20 листопада отримав від сайту HTTP 403. Перевіряйте дату даних і [результат останнього запуску](https://github.com/ABovsh/svitlyachok-data/actions/workflows/collect.yml).

GitHub Actions перевіряє сайт за п’ятихвилинним розкладом. Запуск може затриматися. Помилка читання або перевірки зберігає попередній файл із його датами. Історія змін доступна в Git.

Кожна область має окремий модуль у `providers/` і файл у `data/`. Для додавання області зареєструйте модуль у `collect.py` — спільний workflow підхопить його автоматично. Збій однієї області дозволяє іншим опублікувати перевірені зміни.
