# Графіки відключень для Світлячка

[Графік Чернівецької області](data/chernivtsi.json) містить оприлюднені Чернівціобленерго графіки на сьогодні й завтра. Групи мають номери від 1 до 12. [Джерело](https://oblenergo.cv.ua/shutdowns/)

Для кожної дати за київським часом і групи записано 48 півгодин від опівночі. Значення `1` означає, що світло є, `0` — відключення, `3` — можливе заживлення. Поле `updated` містить час, коли збирач виявив зміну.

Основний збирач працює на сервері в Україні й перевіряє сайт кожні 15 хвилин: сервери GitHub сайт Чернівціобленерго не обслуговує (HTTP 403). GitHub Actions пробує щогодини як другий збирач. Помилка читання або перевірки зберігає попередній файл із його датами. Перевіряйте дату даних; історія змін доступна в Git.

Кожна область має окремий модуль у `providers/` і файл у `data/`. Для додавання області зареєструйте модуль у `collect.py` — обидва збирачі підхоплять його автоматично. Збій однієї області дозволяє іншим опублікувати перевірені зміни.
